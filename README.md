🌱 Smart Plant Monitoring System

A smart IoT-based plant monitoring and automatic irrigation system that monitors soil moisture and controls a water pump automatically.

🚀 Features

- 🌱 Real-time soil moisture monitoring
- 💧 Automatic plant watering
- ⚙️ Pump turns ON when moisture ≤ 40%
- 🛑 Pump turns OFF when moisture ≥ 70%
- 📱 Mobile application for monitoring
- 🔌 Relay-based pump control
- 📊 Simple and user-friendly dashboard
- 🤖 Reduces unnecessary water usage

🔄 Working

The soil moisture sensor continuously measures the moisture level of the soil.

Moisture ≤ 40% → Pump ON 💧

Moisture 41–69% → Maintain current pump state 🌱

Moisture ≥ 70% → Pump OFF 🛑

The system can be implemented using an Arduino/ESP32, soil moisture sensor, relay module, and water pump, with a mobile application for monitoring.

🛠️ Technologies Used

- Arduino / ESP32
- Soil Moisture Sensor
- Relay Module
- Water Pump
- Mobile Application
- IoT / Wi-Fi or Bluetooth
- HTML, CSS & JavaScript

🎯 Objective

The main objective of this project is to automate plant irrigation by monitoring soil moisture and supplying water only when the plant needs it.

🌍 Future Scope

- Multiple plant monitoring
- Temperature and humidity monitoring
- Weather-based irrigation
- Cloud data storage
- Notifications when water is required
- Multiple pump/plant support
